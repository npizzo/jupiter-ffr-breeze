# Earlier three-depth runs and validation archive

[Watch on the gallery](https://npizzo.github.io/jupiter-ffr-breeze/#earlier-archive).

Thirteen movies cover the completed two-day unheated 85°N run; three six-hour polar heating pilots; a frozen partial fine-shear record through day 9.5; the moist resting-atmosphere test; shear grid, balance and uniform-tracer tests; the earlier large-grid probe; and the two one-day validations for the 100-day campaign.

All use actual saved vorticity at three heights. Vorticity appears above tracer where tracer was saved; the old large-grid probe has vorticity only. The moist-rest movie adds condensate. Scales are fixed across each entire movie and explicitly recorded; different validation movies do not share vorticity limits. The partial fine-shear record is not a completed ten-day run. No running simulation was modified.

All rendering and decoding ran on Unity (1431928, followed by 1432050 for watchable playback rates). Playback retiming keeps every saved frame in order, with no temporal interpolation. [Publication record](publication.json); per-movie JSON and model metadata accompany each MP4.
