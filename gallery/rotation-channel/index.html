What this comparison tests

The two cases start with identical wall-compatible mixed-sign eddies at RMS speed 0.136. They have the same cap, bottom heating, dissipation, grid and rotation at the channel center. Only beta differs. Both use periodic east–west boundaries and impermeable, stress-free, insulated north–south walls.

The geometry is a 4×4×1 box on a 256×256×80 grid. With the chosen 100-km depth mapping it is 400 km wide. At 67.5°N, the imposed nondimensional beta is 0.00321168885 and f₀=5.54327720: f changes by only 0.232% across the channel. This is a weak-beta regional test, not a full GRS-scale domain.

The original doubly periodic Ω=3 run has different boundaries and initial eddy geometry. Differences from that run cannot be attributed to beta alone; the paired channel control is essential. Plane statistics do not by themselves establish a persistent large-scale vortex or an inverse cascade. The pre-existing compressible energy-budget residual remains unresolved.
