# Channel-width comparison: 35°N, days 50–100

Read-only comparison of the completed 6,000-km and 12,000-km meridional channels, computed on Unity. Results are presented beneath the wider-channel movie on the [GitHub Pages gallery](https://npizzo.github.io/jupiter-ffr-breeze/#ferrel35-wide100).

The audit compares the same physical interior, separate distances from the north and south walls, persistence across two 25-day windows, and momentum accounting. The wider run has every-step native momentum integrals; the older narrow run has sampled centered diagnostics only. Numerical closure is not by itself evidence of eddy-driven Ferrel cells.

[Method and source](../../scripts/ferrel35_width_audit_v1/README.md). Numerical report, figures and validation manifest accompany this record after publication completes.
