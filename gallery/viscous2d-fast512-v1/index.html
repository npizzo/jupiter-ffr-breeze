512²: forced and unforced flow through t = 400.

Two matched Oceananigans runs, completed on Unity through dimensionless model time t = 400. Both begin with the same random turbulent flow. The original t=0–200 runs are joined to continuations from their saved states. The continuations use the validated efficient implementation, with unchanged physics and timestep.

Parameters and display

The t=200–400 continuations completed on one Unity CPU each: 66 minutes 30 seconds forced and 48 minutes 16 seconds unforced. Native viscosity and cached FFT forcing replaced the allocation-heavy implementation after equation-equivalence, restart and performance checks passed. Validation record.

512 × 512 cells in a periodic 2π × 2π horizontal box; constant f = 1, β = 0. Ordinary Laplacian viscosity ν = 10⁻⁴; no drag or hyperviscosity. Fixed timestep Δt = 0.0025. The initial random vorticity occupies wavenumbers 12–16. The forced run applies a k²ζ growth term with a = 2 × 10⁻⁴ in that band, excluding kx = 0; the control has a = 0.

All movies use one fixed symmetric asinh vorticity scale (linear width 0.1), spanning the full extrema across both runs and all frames. No clipping, framewise normalization or interpolation. The posters show the final state. Duplicate segment-endpoint frames are checked for equality and shown once.

This minimal horizontal 2D model tests the response to prescribed instability forcing. It does not simulate convection itself; constant f alone cannot select vorticity sign in incompressible horizontal 2D flow. Morphology alone does not establish inverse energy transfer or a sign-selection mechanism. No comparison with the 256² runs is presented.
