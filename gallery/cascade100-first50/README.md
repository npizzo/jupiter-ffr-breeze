# Coarse f-plane heating comparison, days 0–50

**Publication pending.** Unity rendering job **67036876** depends on successful completion of the unheated day-50 segment, job **66992558**. The heated day-50 segment has completed. The landing page will be updated only after rendering, verification, upload and deployment.

Planned movies: comparison_0_50days.mp4, heated_0_50days.mp4, and unheated_0_50days.mp4. Each includes all 401 saved times at three-hour intervals from day 0 through day 50 without temporal interpolation. Separate-case movies inherit the paired comparison's fixed color scales.

The paired view uses three depth columns and four rows: heated vorticity/tracer, then unheated vorticity/tracer. Individual views use three columns and two rows. Actual heights are 19.6875, 59.0625 and 100.3125 km above the bottom.

These are dry, anelastic f-plane experiments with 1200-km random seeds, no imposed shear, and a 256 × 256 × 64 grid in a 6000 × 6000 × 120-km channel. Heating is 162 versus 0 W/m²; stable-cap and heat-budget feedback treatments are shared. Fifty days is an intermediate milestone in the 100-day campaign. Morphology alone does not establish an inverse cascade, and fine convective structures are not demonstrated to be resolution-converged.

Vorticity uses symmetric asinh scales of width 0.1 in ζ/f₀, full per-depth extrema shared across both cases and all fifty days. Tracer uses a fixed asinh scale of width 0.01 and physical concentration labels. Rendering stays on Unity; raw fields are not published or downloaded.
