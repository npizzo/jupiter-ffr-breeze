# Projected nonlinear-stress experiment

Four horizontal 2D Oceananigans cases, 256², dimensionless t=0–400. Simulations and rendering completed on Unity.

[Watch the gallery](https://npizzo.github.io/jupiter-ffr-breeze/gallery/stress2d-v1/) · [Protocol and validation](../../experiments/stress2d-v1)

This is a constitutive hypothesis, not resolved convection. Movies use one horizontal plane, no tracer, and fixed shared vorticity colors. The stress directly forces low modes: morphology alone does not establish an inverse cascade.
