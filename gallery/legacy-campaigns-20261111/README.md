# Historical single-height vorticity archive

[Watch all 34 movies on the gallery](https://npizzo.github.io/jupiter-ffr-breeze/#legacy-archive).

The user explicitly authorized single-height movies on November 11, 2026 for these older experiments. Each movie shows the one height actually saved; other vorticity depths and passive tracer were not saved and are not fabricated. New simulations retain the three-depth requirement.

The archive covers the original and revised controlled-convection runs, neutral-layer tests, seeded turbulence, stronger heating, five-day comparisons, the original twenty-day f/beta and periodic cases, their shorter refined cases, and the initial four-hour pilot. The interrupted original controlled-convection attempt is labeled partial. These historical cases used different cap and heating treatments and should not be interpreted as one matched ensemble.

Every available frame is retained in chronological order. Vorticity uses a symmetric asinh scale of width 0.1 in ζ/f₀, fixed over each movie; limits differ between cases. No clipping or temporal interpolation is used. Per-movie JSON files list physical times, sampled height, frames, source, normalization, encoding hashes and full-decode checks. Model metadata accompany each movie.

All rendering and validation ran on Unity, array job 1432140 (all four tasks completed). Job 1432280 created smaller web copies of the longest three movies while preserving dimensions, frame counts, physical times and scales. Original renderings remain on Unity. This is an output archive, not an assertion of numerical convergence or Jovian fidelity.
