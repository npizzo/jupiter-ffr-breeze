# Saved-output inventory

The inventory was generated on Unity by job 1431964, reading metadata and saved-frame schemas. It lists 168 output records, including segments, validation tests and development attempts. It is not a list of 168 independent science experiments. Metadata marked RUNNING may be stale; it does not describe current scheduler state.

[CSV inventory](inventory.csv) · [Detailed inventory](inventory.json) · [Watch gallery](https://npizzo.github.io/jupiter-ffr-breeze/).

The publication adds complete 0–100-day heating/control movies, completed 48-hour Ferrel output, thirteen earlier three-depth movies and 34 historical single-height movies. Previously published 30-day f-plane, 20-day f/beta, ten-day shear, moist-plume, large-eddy validation and 75-day gamma movies are preserved. Restart/smoke fragments remain technical records. Superseded failed development outputs are not presented as completed science. Pending refinements and runs with no saved output are not rendered.

The historical single-height exception was explicitly approved by the user. Missing physical depths or tracers are never inferred. All scientific processing, rendering and media validation stayed on Unity; only finished publication assets were transported for GitHub upload.
