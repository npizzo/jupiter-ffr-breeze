# Matched internal-deformation pair

Authorized 26 November 2026. A separate, unforced 3D anelastic experiment; no active convection campaign is changed.

Phase seed 261130 was selected before evolution by an initialization-only CPU check. The original seed was slightly statically unstable in the strong-deformation case. Seeds were checked in ascending order against a fixed minimum N² greater than 10% of background criterion; 261130 was the first to pass (17.1%). Both cases use this same seed. No evolved vortex preference was used for selection.

Two 128 x 128 x 64 periodic horizontal boxes have the same velocity seed, f=0.1, Ro=0.1 and constant viscosity (nominal Re=2000). Vertical rotation only. No beta, jet, heating, cooling, Smagorinsky closure, drag or prescribed vorticity-sign forcing. Scalar explicit diffusivity is zero; WENO9 supplies numerical scalar/momentum dissipation. The top and bottom are impermeable and stress-free with no scalar flux.

The common, vertically varying pressure mode has stronger upper flow and return flow below; its reference shape comes from the internal-mode eigenproblem using the adiabatic reference density. Each stable reference potential-temperature profile is exponential, with its constant N² calibrated to the discrete first internal mode. Targets L/Ld=0.5 and 2.0, where Ld=c1/f. The actual eigenvalue, mode-shape mismatch, density contrast and initial stability are saved. Density profiles differ slightly as required by hydrostatic thermodynamics; same velocity does not imply identical mass-weighted energy. Initial buoyancy/available potential energy necessarily differ.

L is sqrt(face horizontal velocity variance / native vertical vorticity variance). U is horizontal face RMS where the common vertical mode has maximum amplitude. This gradient-length convention is not the Fourier wavelength. Random-phase modes have integer squared wavenumbers 5 and 13 and odd nx+ny; half-box diagonal translation changes the velocity and vorticity signs. Initial skewness is zero at every depth. The thermal field is initialized from geostrophic pressure plus a nonlinear horizontal pressure correction and exact dry anelastic buoyancy inversion. This is approximate balance with measured discrete errors, not an exact steady solution.

Both integrate for 25 initial L/U turnover times (t=2500 in these units), with 0.1-turnover three-depth vorticity, tracer, w and buoyancy frames, full volumes every 5 turnovers and checkpoints every 2.5. APE is a small-amplitude proxy, not a claim of exact energy closure. Initial static stability is mandatory; subsequent dynamically generated overturning is recorded. Finite-state, positive-temperature, continuity, conserved-scalar and Mach guards remain active.

CPU preflight uses the actual driver, checks BOTH full-resolution initial conditions and brief projected evolution, then exercises complete small-grid output/readback/restart and resting-state paths. A source/environment fingerprint binds the receipt to the GPU jobs. Each job repeats GPU output/restart validation, is limited to six GPU hours, and does not automatically extend. All scientific computations remain on Unity.

This tests preferential vortex evolution through an internal deformation mode, not convection-driven generation, an externally compressible Lamb mode, or a meddy mixing-patch experiment. Compare signs at the same height; do not cancel upper and lower baroclinic vorticity by using only a depth average. A positive outcome requires a persistent coherent anticyclone, not merely negative raw skewness.
