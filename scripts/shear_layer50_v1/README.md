# Fifty-day shear × upper-layer stratification experiment

The user explicitly extended all six Breeze cases to 50 Earth days on 2026-11-18: previous LSV formation became clear only around days 40–50. Ten days is a checkpoint, not an LSV acceptance/rejection endpoint. The original six-case physical design remains unchanged; see ../shear_layer_v1/README.md for equations, geometry, controls, and limitations.

Each continuation reads its own completed day-10 checkpoint and runs to day 50, preserving all initial conditions, reference state, heating, viscosity, cap control, f, and numerical discretization. Only `stop_seconds` and the wall-clock allowance change. The original running source and configurations are not edited. Source hashes, complete day-10 status, matching parameters, and a unique final checkpoint are required before starting; checkpoint checksums are recorded. The existing checkpoint test found a maximum velocity difference of 4.08e-12 m/s and identical saved vorticity/tracer planes.

All six initial runs must complete successfully before the continuation array is released. The array runs at most one L40S GPU job at a time, with a 2.5-hour hard limit per continuation and a 140-minute internal stop that retains a checkpoint. That adds a maximum of 15 GPU-hours; the early measured forecast is approximately 8–9 additional GPU-hours, subject to evolving CFL limits. A stopped or incomplete case blocks the completion render; it is not reported as day 50. No extension beyond day 50 is authorized by this campaign.

The previously queued ten-day render is superseded by a new completion render. It joins the original and continued outputs on Unity, checks every saved time from 0 to 50 days and the shared day-10 boundary, then renders three stable/neutral comparisons (one for each initial shear). Every movie has three depth columns and four rows: stable vorticity/tracer followed by neutral vorticity/tracer. Scales are fixed in time, and actual saved heights are displayed. Raw fields stay on Unity.

The predeclared mature diagnostic window is days 40–50. Compare upper, lower, interface, and full-column nonzonal vorticity statistics and absolute large-scale nonzonal energy. Retain total circulation and the actual evolving zonal shear separately. Temporal samples are correlated, and a single seed does not establish an ensemble preference. Persisting boundary effects, insufficient resolved convection, or decayed initial shear must be reported rather than interpreted as evidence against either mechanism. Fifty days is grounded in the earlier runs but does not guarantee saturation in this smaller domain.
